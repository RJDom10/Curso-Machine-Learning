# Módulo 07: Support Vector Machines (SVM) - Clasificación

Estructura avanzada y modularizada para la enseñanza de SVM:

1. **`01_Fundamentos_SVM_Margen_Maximo_y_Soft_Margin.ipynb`**: Teoría del margen, vectores de soporte, y parámetro de regularización $C$.
2. **`02_El_Truco_del_Kernel_y_No_Linealidad.ipynb`**: Mapeos no lineales usando Kernels (RBF, Polynomial, Linear).
3. **`03_Hiperparametros_C_y_Gamma_GridSearch.ipynb`**: Tuning del compromiso sesgo-varianza mediante validación cruzada. Uso obligatorio de `StandardScaler`.
4. **`04_SVM_Multiclase_y_LinearSVC_Escalabilidad.ipynb`**: OvO vs OvR y comparativa de rendimiento computacional ($O(N^3)$ vs $O(N)$).
5. **`05_Ejercicios_Support_Vector_Machines.ipynb`**: Retos prácticos.
6. **`06_Soluciones_Support_Vector_Machines.ipynb`**: Código resuelto.
